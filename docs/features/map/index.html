POST /v1/map

Hosted: https://api.fastcrw.com · Self-hosted: http://localhost:3000

Auth (hosted only): Authorization: Bearer $CRW_API_KEY

Self-hosted: no auth required by default.

Map discovers URLs reachable from a seed without scraping page content. Use it to plan a crawl, build a sitemap, or filter links before a scrape pass.

Request body

{
  "url": "https://example.com",
  "limit": 100,
  "maxDepth": 2,
  "useSitemap": true
}

Required: url. Optional: limit, maxDepth (default 2), useSitemap boolean (default true), crawlFallback boolean (default true), timeout seconds.

Response shape

{
  "success": true,
  "data": {
    "links": [
      "https://example.com/",
      "https://example.com/docs",
      "https://example.com/docs/quickstart"
    ],
    "sitemaps": [
      "https://example.com/sitemap.xml",
      "https://example.com/product-sitemap.xml"
    ]
  }
}

data.links is a flat string array (not objects); dedup is applied. data.sitemaps holds the sitemap documents that were fetched and parsed during discovery, kept separate because a sitemap file is not a page.

Python (stdlib)

#!/usr/bin/env python3
import json, os, urllib.request

req = urllib.request.Request(
    "https://api.fastcrw.com/v1/map",
    data=json.dumps({"url": "https://example.com", "limit": 50}).encode(),
    headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {os.environ['CRW_API_KEY']}",
    },
    method="POST",
)
with urllib.request.urlopen(req) as r:
    body = json.loads(r.read())

for link in body["data"]["links"][:20]:
    print(link)

for sitemap in body["data"]["sitemaps"]:
    print("sitemap:", sitemap)
# Run with: python3 map.py
